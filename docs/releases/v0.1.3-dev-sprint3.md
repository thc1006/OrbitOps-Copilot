## 8. Anti-pattern accountability (cross-PR)

The Sprint-3 PR train surfaced 5 anti-patterns, each of which was acknowledged in writing and held in subsequent PRs:

1. **prose-not-grep** (PR #75/#76): writing prose without grep'ing first → "path/function/var/count must be grep-verified before write"
2. **Edit-tool-no-op** (PR #77/#78): trusting tool return success without verifying → "POST-WRITE re-grep / json.load / find verifies effect"
3. **cross-page semantic mismatch** (PR #79): `colorFromSnr ≤6/≤12 dB` clashed with `BeamView.health` thresholds → "use `colorFromHealth(health)` directly"
4. **NaN propagation** (PR #79): `Math.max(NaN, 5) === NaN` → `Number.isFinite()` guard
5. **first-call-only ignore** (PR #80): `initI18n("zh-TW")` early-returned after init → `if (lng !== current) await changeLanguage(lng)`

Sprint-3 self-review (PR #81 fix-pack) added a 6th: **partial-migration in feedback strings** — extracted to `scenarios.feedback.*` with i18next interpolation + `$t()` references, plus `zh-no-english-leak.test.tsx` to catch the class.

### Tag policy (decision 2026-05-07)

**The tag is NOT being moved.** PR #87/#88 are treated as post-tag hot-fix on the visual layer, not as a re-cut of the release. Rationale:

1. The live cluster `cloudnative-dev-telco` (kubeadm @ 31.41.34.19) was updated to image SHA `14bb344edb44` which **already includes both fixes**. Anyone pulling tag `v0.1.3-dev-sprint3` and rebuilding will get the older (Ion-warning + flicker-bug) UI; the live cluster is the durable demo surface.
2. Re-tagging `v0.1.3-dev-sprint3` on `main` would mean GitHub Release HTML, mirror caches, and any downstream `git fetch --tags` consumers see a different commit under the same tag — confusing for the 1 PR worth of value being captured.
3. Next formal cut will be `v0.1.4` (or `v0.1.3-dev-sprint3.1` if a patch-level convention is preferred), at the start of Sprint-4 or whenever a non-trivial change accumulates.

If a future contributor needs to reproduce the *exact* demo state shipping on the live cluster, the rebuild target is `main` at `19a28ef` or later, **not** `v0.1.3-dev-sprint3`. This errata is the only place that distinction is documented; verify.sh + Makefile do not reference the tag for build purposes.

### Anti-pattern accountability update

PR #88 surfaced **Chain #6 — Resium reference-stability** (now in `docs/reviews/anti-pattern-checklist.md`):
inline `Color.fromCssColorString(...)` / `new Cartesian2(...)` in JSX → new references every render → Resium shallow-equal diff triggers Cesium entity recreation → visible flicker. Pattern: hoist statics to module scope, wrap dynamics in `useMemo`. Codified as AC-S004-13e.8 + ADR-011 Appendix A + verify-grep one-liner.

PR #88 also surfaced a process anti-pattern (Chain #X): 8 commits chasing a moving visual target without a regression test on each step. Sprint-3 review action: **for visual bugs, write the failing test FIRST**.
